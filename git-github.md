Git est un logiciel de versionnement de code et permet de travailler en equipe en local tandis que github est un site d'hebergement de stockage de fichiers en ligne. 

Ils sont tous les deux differents mais vont de pairs car : pour que github fonctionne, git doit etre installe sur la machine

Caracteritiques de git & github 

Pour git on a le controle de version, l'architecture distribuee, la gestion des branches et la collaboration. 

Pour github, on a l'hebergement cloud, l'historique git et la collaboration

Les commandes git a retenir :
git init : pour initialiser le depot en local
git-clone : pour cloner le depot distant
git-checkout [nom de la branche] : pour le choix de la branche 
git-branche: pour la creation d'une nouvelle branche
git-push : pour synchroniser 
git-commit -m: pour enregistrer les modifications des fichiers suivi d'un message explicatif


Pour github : 
git-remote add otrigin : pour le lier le projet local vers github
git push -u origin main : envoyer le code push
